# Parking System

Backend-система для управления парковкой.

## Стек

- Java 17+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- REST API
- Swagger / OpenAPI
- Docker
- Maven

## Функциональность

### Vehicle

- Создание автомобиля
- Получение списка автомобилей
- Получение автомобиля по номерному знаку
- Изменение автомобиля
- Удаление автомобиля

### Parking Spot

- Создание парковочного места
- Получение списка всех мест
- Получение свободных мест
- Получение места по ID
- Изменение места
- Удаление места

### Parking Session

- Въезд автомобиля
- Проверка существования автомобиля
- Проверка существования парковочного места
- Проверка совместимости типа автомобиля и места
- Проверка доступности парковочного места
- Выезд автомобиля
- Расчёт стоимости парковки
- Освобождение парковочного места

## Запуск PostgreSQL

PostgreSQL запускается в Docker-контейнере.

Создать контейнер:

```bash
docker run --name parking-postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_USER=postgres \
  -p 5432:5432 \
  -d postgres
